# Solana

Практика по Solana / Anchor по неделям. Контракт Simple Vault на Anchor 0.31.1, тесты на devnet.

Каждая папка `Week-N` — отдельный проект с кодом этой недели и выполненными заданиями.
Подробности, запуск и ожидаемый вывод тестов — в README внутри папки.

| Неделя | Папка | Задания | Что сделано |
|---|---|---|---|
| 8 | [Week-8](./Week-8) | 1–3 | `created_at`, `close_user_card`, пауза на создание карточек |
| 9 | [Week-9](./Week-9) | 1–4 | комиссия 1% на `fee_wallet`, минимальный депозит, пауза депозитов, тест на доли трёх пользователей |
| 10 | [Week-10](./Week-10) | 1–6 | `withdraw_all`, закрытие пустой карточки с возвратом ренты |
| 11 | [Week-11](./Week-11) | 1–6 | свои токены и CLMM-пул на Raydium devnet |
| 12 | [Week-12](./Week-12) | 1–7 | swap через Raydium, ограничение swap до 50% TOKEN_A |
| 13 | [Week-13](./Week-13) | 1–9 | позиция в CLMM-пуле, `increase_liquidity`, учёт собранных комиссий |

## Week 8

Vault для SPL-токена и личные карточки пользователей.

1. В карточку добавил поле `created_at` — время создания.
2. Добавил `close_user_card`: владелец закрывает карточку и получает ренту обратно.
3. Добавил флаг `paused` и инструкцию `set_paused` для админа. Пока vault на паузе, новые карточки не создаются.

## Week 9

Депозит токенов в vault и выдача share-токенов.

1. С каждого депозита 1% уходит на `fee_wallet`, shares начисляются с остатка.
2. Минимальный депозит — 1 токен, меньше нельзя.
3. Админ может поставить vault на паузу, тогда депозиты не проходят.
4. Написал тест, где три пользователя вносят разные суммы, и проверил, что доли по shares совпадают с их вкладами.

## Week 10

Вывод токенов: shares сжигаются, токены возвращаются пользователю.

- Задания 1–4 из недели 9 перенесены сюда.
5. Добавил `withdraw_all` — вывод всех shares одним вызовом.
6. `close_user_card` закрывает карточку, только если shares не осталось, и возвращает ренту.

## Week 11

Свои тестовые токены и свой CLMM-пул на Raydium (devnet).

- Скрипт `yarn create-pool` создаёт два токена, минтит их на кошелёк и создаёт пул `TOKEN_A / TOKEN_B`.
- Адреса токенов и пула сохраняются в `devnet-pool.json`.
- Мой пул: [6VHdA1GnZfxPBBo89jTsSbjGeX1AEhpoKMV5YP9uBDTg](https://explorer.solana.com/address/6VHdA1GnZfxPBBo89jTsSbjGeX1AEhpoKMV5YP9uBDTg?cluster=devnet)
- Контракт на этой неделе не меняется, задания 1–6 перенесены из недели 10.

## Week 12

Vault меняет свои токены через пул Raydium CLMM (CPI в Raydium).

- Задания 1–6 перенесены и работают вместе с Raydium.
7. Добавил ограничение: за один swap A → B нельзя потратить больше 50% TOKEN_A vault. Тесты: обмен 496 из 990 и всего баланса отклоняется, обмен 300 проходит.

## Week 13

Vault открывает позицию в CLMM-пуле Raydium, собирает комиссии и закрывает позицию.

- Задания 1–7 перенесены из недели 12.
8. Добавил `increase_liquidity`: админ докладывает токены vault в уже открытую позицию.
9. В `VaultState` добавил `total_fees_a` и `total_fees_b` — сколько комиссий vault собрал за всё время. Считается при `collect_fees` и `close_position`.

## Запуск

Для любой недели, например последней:

```bash
cd Week-13
yarn install
anchor build
anchor deploy --provider.cluster devnet
yarn test
```
