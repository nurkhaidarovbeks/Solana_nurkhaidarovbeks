# Solana

Практика по Solana / Anchor по неделям. Контракт Simple Vault на Anchor 0.31.1, тесты на devnet.

Каждая папка `Week-N` — отдельный проект с кодом этой недели и выполненными заданиями.
Подробности, запуск и ожидаемый вывод тестов — в README внутри папки.

| Неделя | Папка | Что сделано |
|---|---|---|
| 8 | [Week-8](./Week-8) | `created_at`, `close_user_card`, пауза на создание карточек |
| 9 | [Week-9](./Week-9) | комиссия 1% на `fee_wallet`, минимальный депозит, пауза депозитов, тест на доли трёх пользователей |
| 10 | [Week-10](./Week-10) | задания 1–4, `withdraw_all`, закрытие пустой карточки с возвратом ренты |
| 11 | [Week-11](./Week-11) | свои токены и CLMM-пул на Raydium devnet, задания 1–6 |

## Week 8

Vault для SPL-токена и личные карточки пользователей.

- В карточку добавил поле `created_at` — время создания.
- Добавил `close_user_card`: владелец закрывает карточку и получает ренту обратно.
- Добавил флаг `paused` и инструкцию `set_paused` для админа. Пока vault на паузе, новые карточки не создаются.

## Week 9

Депозит токенов в vault и выдача share-токенов.

- С каждого депозита 1% уходит на `fee_wallet`, shares начисляются с остатка.
- Минимальный депозит — 1 токен, меньше нельзя.
- Админ может поставить vault на паузу, тогда депозиты не проходят.
- Написал тест, где три пользователя вносят разные суммы, и проверил, что доли по shares совпадают с их вкладами.

## Week 10

Вывод токенов: shares сжигаются, токены возвращаются пользователю.

- Задания 1–4 те же, что в неделе 9, сделаны и здесь.
- Добавил `withdraw_all` — вывод всех shares одним вызовом.
- `close_user_card` закрывает карточку, только если shares не осталось, и возвращает ренту.

## Week 11

Свои тестовые токены и свой CLMM-пул на Raydium (devnet).

- Скрипт `yarn create-pool` создаёт два токена, минтит их на кошелёк и создаёт пул `TOKEN_A / TOKEN_B`.
- Адреса токенов и пула сохраняются в `devnet-pool.json`.
- Мой пул: [6VHdA1GnZfxPBBo89jTsSbjGeX1AEhpoKMV5YP9uBDTg](https://explorer.solana.com/address/6VHdA1GnZfxPBBo89jTsSbjGeX1AEhpoKMV5YP9uBDTg?cluster=devnet)
- Контракт на этой неделе не меняется, задания 1–6 перенесены из недели 10.
